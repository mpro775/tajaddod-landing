# Tajaddod Landing V2

نسخة محسّنة بالكامل للاندنج بيج الخاصة بتجدد، مبنية كصفحة عربية RTL تعريفية بدون باك إند وبدون منطق بيع مباشر.

## ماذا تغير؟

- تحويل الصفحة من قالب كروت عام إلى **Corporate Digital Showroom**.
- هيرو جديد قوي يوضح أن تجدد تمثل منظومة علامات متخصصة في الكهرباء والطاقة.
- فصل تخصصات البراندات:
  - **CNC**: قواطع، حماية، تحكم صناعي، مؤقتات، سكاكين تحويل، طبالين، وحلول DC للطاقة الشمسية.
  - **Liper**: إضاءة داخلية وخارجية وكشافات شمسية.
- إضافة قسم منتجات مختارة من قاعدة البيانات كعرض تعريفي، بدون أسعار وبدون سلة.
- إصلاح مشكلة `package-lock.json` بحيث يعمل `npm ci`.
- إضافة بدائل SVG مؤقتة لكل منتج، قابلة للاستبدال لاحقاً بصور حقيقية بنفس المسارات.
- تحسين الأنيميشن عبر GSAP مع احترام `prefers-reduced-motion`.

## التشغيل

```bash
npm ci
npm run dev
npm run build
npm run preview
```

تم اختبار `npm ci` و `npm run build` بنجاح.

## أهم ملفات التعديل

- بيانات الموقع والتواصل: `src/data/site.ts`
- بيانات البراندات: `src/data/brands.ts`
- المنتجات المختارة: `src/data/products.ts`
- مجالات التغطية: `src/data/coverage.ts`
- رحلة الطاقة ودور السوق: `src/data/journey.ts`
- التصميم العام: `src/styles/global.css`

## الصور

الصور الحالية داخل `public/assets/products` هي SVG placeholders أنيقة حتى لا يظهر التصميم مكسوراً. عند تجهيز صور المنتجات الحقيقية، استبدل كل ملف بنفس المسار والاسم أو عدّل مسار الصورة في `src/data/products.ts`.

راجع: `docs/ASSETS_REPLACEMENT_GUIDE.md`
